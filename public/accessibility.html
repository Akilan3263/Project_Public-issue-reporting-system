RoadWatch UK — Accessibility

Accessibility statement

RoadWatch UK aims to make this service usable for as many people as possible.

You should be able to:

  • zoom in up to 200% without problems
  • navigate most of the service using a keyboard
  • use the service with screen readers

If you need information in a different format or find any accessibility issue, please use our feedback page.
